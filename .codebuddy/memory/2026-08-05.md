## 对比视图 Bug 修复（拖拽耦合 + 状态一致性）

**问题**：home 与 compare 同时注册 `onDragDropEvent`，async cleanup race 导致 home 的 listener 残留，拖拽到 compare 会触发 home 的 `navigate(/editor)`；home 只 `clearFiles()` 不清 companies，状态分裂；拖拽区全宽不响应珊格

**修复**：
- **新建 `src/hooks/use-global-drag-drop.ts`**：singleton 监听器（模块级 `dropHandler`/`hoverHandler` 变量 + `refCount`），按 `onDragDropEvent` 异步 Promise + 引用计数管理生命周期；最新注册的 handler 生效，旧 unmount 时自动让位，彻底解耦 home/compare
- **`home-page.tsx`**：移除本地 `onDragDropEvent`，改用 `useGlobalDragDrop`；`clearFiles()` → `clearAll()`（同时清 files + companies）；删未用的 `getCurrentWebview` 导入
- **`drop-zone.tsx`**：改用 `useGlobalDragDrop`；`ingestPaths` 用 `useCallback` + `ctxFilesRef` 避免闭包陈旧；hover 反馈只在光标在 zone 内时点亮
- **`compare-page/index.tsx`**：DropZone 移入 grid 的第一个 cell，与 CompanyCard 共用响应式 `grid-cols-2 md:grid-cols-3 lg:grid-cols-4`，照片墙规范
