## 风险报告 Bug 修复

- **Bug：3 家公司时 hero 标题只显示 2 家**：原因是 hero 用了 `involvedCompanyIds`（只含 findings 里出现过的公司）。Rust 端 `compare_files` 只对 company_a × others 做两两对比，当 company_a=A、其他=B/C 时，findings 只涉及 {A,B} 或 {A,C}，从未共同涉及 B+C 的 finding，所以 `involvedCompanyIds` 可能缺第三家。修复：hero 改用 `companySnapshots`（全部公司），未涉及的公司 chip 加 `opacity-50` + `title="未涉及风险"`。
- **Bug：2 家公司对阵图卡片上下堆叠**：原用 `flex flex-nowrap` + `min-w-`，flex item 没有 max-width 限制，被内容自然撑宽；sm+ `flex-wrap` 让每张卡撑满一行。修复：1/2/3 家改用 `grid` 严格分配列数（`grid-cols-1` / `sm:grid-cols-2` / `sm:grid-cols-3`），**只有 ≥4 家才走 ScrollArea 横滚**。`CompanyBattleRow` props 改 `(snapshots, involvedIds)`，不再重复计算。
- hero 标题 `cn(... !isInvolved && findings.length > 0 && "opacity-50")`：仅当存在 findings 但该公司未卷入时降透明度，避免"无风险时全部 50%"误导。

  - 实施要点：`aria-hidden` + `tabIndex={isActive ? 0 : -1}` 让 SR 与键盘焦点在 collapsed 状态下不漂到隐藏项。

为何用 `min-[820px]:` 而非 sm/md：项目 Tauri 窗口默认 880×580、最小 780×520，常见分辨率就在 780-900 区间，Tailwind 默认断点（sm=640/md=768/lg=1024）都不能稳定覆盖；用 arbitrary 820px 命中 880，留 60px 安全边。

效果：顶部极简、主题切换隐藏状态时只占 28×28 圆形，hero 只剩文本+chip 信息密度，拖拽区保持原紧凑 dashed 区，下方两张卡不变。

## 首页第三次精修：ThemeSwitch 丝滑 + 拖拽区居中 + EntryCard 去渐变

PM/用户三个细化要求：

1. **ThemeSwitch compact 展开"跳动"** —— 改用「active 永远在第一位 + 单维度过渡」机制。
2. **右拖拽区要小、要上下左右等距居中** —— 用外层 `items-center justify-center p-2` + 内层 `max-w-72`。
3. **底部 EntryCard 重新设计** —— 去掉橙/紫渐变背景，徽章改边框型，hover 高亮 tone 自家 accent。

实施（2026-08-06）：

### ThemeSwitch 丝滑展开（`src/components/chrome/theme-switch.tsx`）

跳动感根因：旧版同时切 `gap` + `padding` + `max-w` + `margin` + `size`，属性叠加产生不齐滑动。

新机制：
- **active 项永远 `order: -10` 锁定第一位** → 视觉中心不漂移。
- 容器只 transition `gap`（collapsed 0 ↔ expanded 0.5），其他维度不参与。
- active 项的 label 用 `<span class="transition-[max-width,opacity]">` 内嵌动画：compact 时 `max-w-0 opacity-0`，hover 时 `max-w-32 opacity-100`。
- 非 active + 隐藏项用 inline style `{ maxWidth: 0, marginLeft: -2, paddingInline: 0, opacity: 0 }`，hover 反转。
- 所有 button 都带 `transition-[opacity,margin,max-width,padding,background-color,color,box-shadow] duration-200 ease-out`，单维度同步动画。

效果：active 项中心点纹丝不动，hidden 项从右往左平滑滑出，无 layout-shift。

### 拖拽区居中（`src/pages/home-page/index.tsx`）

```tsx
<section className="flex min-h-0 items-center justify-center p-2">
  <div className="flex w-full max-w-72 flex-col rounded-xl border border-dashed ... p-4">
    <DragOrUploadZone ... />
  </div>
</section>
```

- 外层 `flex items-center justify-center p-2`：让 cell 内拖拽区上下左右等距 padding。
- 内层 `max-w-72` (288px) 把拖拽区宽度收住，cell 剩余空间均匀分布。
- 在 880px 窗口下：右 cell ≈ 347px - 内层 288px ≈ 30px 余 → 左右各 30px padding。

### EntryCard 重新设计

旧问题：
- 卡片整体用 `from-{tone}-500/15 to-{tone}-500/0` 渐变 + `border-{tone}-500/20`，背景色块过重。
- badge 用 `bg-red-500 text-white` / `bg-blue-500 text-white`，**与 card accent 颜色不一致**（橙/紫配红/蓝），视觉割裂。
- CTA `text-primary` 永远 primary 蓝，不与 card accent 共振。

新设计（保持 design.md 的 subtle 1px border + 不重 drop-shadow 原则）：
- card 静态：`border border-border/60 bg-card/40`（统一低饱和），tone 区分仅在 hover 时显示。
- card hover：`hover:border-{tone}-500/55 hover:bg-{tone}-500/5`（accent 微亮 + 微弱底色），与 icon/badge/cta 形成 tone 闭环。
- badge：`border-{tone}-500/30 bg-{tone}-500/10 text-{tone}-700`（边框型 + 浅底 + accent 文字），与 hero `FeatureChip` 视觉语言统一。
- icon：`h-8 w-8 rounded-lg bg-{tone}-500/10 text-{tone}-600 dark:text-{tone}-300`（同样 tone accent）。
- CTA：`text-{tone}-600 dark:text-{tone}-300` + `ArrowRight01Icon` size-12，hover 时箭头右滑 0.5。
- 删除 `ring` 字段（原代码没用上）。

Tone style map 重构：
```ts
TONE_STYLES = {
  orange: { card: "border-orange-500/25 hover:border-orange-500/55 hover:bg-orange-500/5",
           icon: "bg-orange-500/10 text-orange-600 dark:text-orange-300",
           badge: "border-orange-500/30 bg-orange-500/10 text-orange-700 dark:text-orange-300",
           cta: "text-orange-600 dark:text-orange-300" },
  violet: { card: "border-violet-500/25 hover:border-violet-500/55 hover:bg-violet-500/5",
           icon: "bg-violet-500/10 text-violet-600 dark:text-violet-300",
           badge: "border-violet-500/30 bg-violet-500/10 text-violet-700 dark:text-violet-300",
           cta: "text-violet-600 dark:text-violet-300" },
}
```

为何 hover 才现 accent：静态时所有 card 视觉权重一致（统一 gray），方便用户聚焦信息；hover 时 accent 浮起来给反馈，符合 design.md「Don't add heavy drop shadows」的克制原则。

新增 import：`ArrowRight01Icon` from `@hugeicons/core-free-icons`。lint 0 报错。
