## 核心事实

前端把**已解析的语义字段**拍平成 `CompareFileInput[]`，越过 IPC 边界交给一个**纯函数内核** `run_compare`；内核用「对齐 → 差异 → 风险 → 归一化」四阶段算出「可渲染结果树」`CompareResult`，前端只做展示投影与导出。解析复杂度在前端资源层，语义计算在 Rust 内核——这就是该程序「前端瘦、后端重」的真实含义。
