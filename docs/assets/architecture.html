元数据编辑流： 页面交互→ documentsResource.show→ trackedInvoke→ Rust parse_*→ metadata Schema 渲染→ replace/batch → save_* 写回
比对 / 隐藏流： 批量拖拽 / 目录扫描→ scan_directory→ compare 内核 (align/diff/rules)→ 前端 findings / groups→ export xlsx 四表
架构要点：① 进程边界隔离——文件 IO 全在 Rust 侧，安全且跨平台；② Schema 驱动——新增格式只需补一个 schema 模块，表单与对比自动适配；③ 资源门面——documentsResource 屏蔽类型差异；④ 比对内核重构——Rust 侧 compare/ 与 TS 侧 selectors.ts 纯函数分层，比对/匹配把"同名文档跨目录对齐"作为一等能力。
