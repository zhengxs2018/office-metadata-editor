## 定位速查

- 想了解**整体怎么搭的** → 01
- 想改**数据结构 / 加字段** → 02 + 05
- 想调**风险规则 / 打分** → 03
- 想加**新文件格式** → 01（格式适配层）+ 04
- 想知道**下一步做什么** → Roadmap
